## 🛒 eCommerce Next.js + Shopify + Stripe

This project is a headless eCommerce application built using Next.js as the frontend, Shopify as the backend (product and inventory management), and Stripe for secure payment processing (test mode).

## 🚀 Features

- ⚡ Fast and responsive UI using Next.js
- 🛍️ Product data fetched from Shopify Storefront API
- 💳 Stripe integration for checkout (test environment)
- 📦 Dynamic product listing and product detail pages
- 🔄 Client-side rendering for smooth user experience
- 🧩 Scalable headless commerce architecture

## 🛠️ Tech Stack

- Frontend: Next.js (React)
- Backend (Headless CMS): Shopify
- Payment Gateway: Stripe (Test Mode)
- Styling: (Add Tailwind/Bootstrap if you used one)
